# qwq AIOps 平台 - 快速开始

## 🎯 5 分钟快速部署

### 步骤 1: 准备环境

确保已安装：
- ✅ Docker 20.10+
- ✅ Docker Compose V2
- ✅ 4GB+ 可用内存
- ✅ 10GB+ 可用磁盘空间

### 步骤 2: 获取代码

```bash
git clone https://github.com/QwQBiG/qwq-aiops.git
cd qwq-aiops
```

### 步骤 3: 配置 AI 服务

**重要**: qwq 是 AI 驱动的平台，必须配置 AI 服务！

#### 选项 A: OpenAI API（简单快速）

```bash
# 1. 复制配置文件
cp .env.example .env

# 2. 编辑配置
nano .env

# 3. 取消注释并填写
AI_PROVIDER=openai
OPENAI_API_KEY=sk-your-api-key-here
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-3.5-turbo
```

#### 选项 B: Ollama 本地模型（免费）

```bash
# 1. 安装 Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 2. 下载模型
ollama pull qwen2.5:7b

# 3. 编辑配置
cp .env.example .env
nano .env

# 4. 取消注释并填写
AI_PROVIDER=ollama
OLLAMA_HOST=http://host.docker.internal:11434
OLLAMA_MODEL=qwen2.5:7b
```

### 步骤 4: 一键部署

**Linux/macOS**:
```bash
chmod +x deploy.sh
./deploy.sh
```

**Windows**:
```bash
start.bat
```

### 步骤 5: 访问系统

部署成功后，打开浏览器访问：

🌐 **http://localhost:8081**

默认账号：
- 用户名: `admin`
- 密码: `admin123`

## 🔧 常用命令

### 服务管理

```bash
# 启动服务
docker compose up -d

# 停止服务
docker compose down

# 重启服务
docker compose restart

# 重新构建
docker compose up -d --build
```

### 日志查看

```bash
# 查看实时日志
docker compose logs -f qwq

# 查看最近 100 行
docker compose logs --tail=100 qwq

# 查看所有服务日志
docker compose logs -f
```

### 数据备份

```bash
# 备份数据目录
tar -czf backup-$(date +%Y%m%d).tar.gz data/

# 备份数据库
docker compose exec qwq-mysql mysqldump -u root -p qwq > backup.sql
```

## ⚠️ 常见问题

### 问题 1: 端口被占用

**错误**: `bind: address already in use`

**解决**:
```bash
# 查找占用进程
lsof -i :8081

# 终止进程
kill -9 <PID>

# 或修改端口
# 编辑 docker-compose.yml，修改端口映射
```

### 问题 2: AI 不工作

**检查**:
```bash
# 查看 AI 相关日志
docker compose logs qwq | grep AI
```

**解决**:
1. 确认 `.env` 中 AI 配置正确
2. 如果用 OpenAI，测试 API Key
3. 如果用 Ollama，确认服务运行
4. 重启服务: `docker compose restart qwq`

### 问题 3: 构建失败

**解决**:
```bash
# 1. 清理缓存
docker system prune -a

# 2. 重新构建
docker compose build --no-cache

# 3. 启动
docker compose up -d
```

### 问题 4: 无法访问前端

**解决**:
1. 检查容器状态: `docker compose ps`
2. 检查防火墙设置
3. 尝试使用 `http://127.0.0.1:8081`
4. 查看日志: `docker compose logs qwq`
